```html AI Screen Reader - Installation Guide

AI Screen Reader

Follow the steps below to download and install the AI Screen Reader Chrome extension.

Step 1: Download the Extension

First, download the AI Screen Reader extension ZIP file to your computer.

Download ZIP File
Your download should begin shortly.

The ZIP file contains the latest version from the main branch of the GitHub repository.

Step 2: Extract the ZIP File

Locate the downloaded ZIP file on your computer, right-click it, and select "Extract All..." on Windows.

On Mac, double-click the ZIP file to extract it.

After extracting the repository, open the extracted folder and locate the AI Screen Reader folder.

Remember the folder location because you will need it in Step 5.

Step 3: Open Chrome Extensions Page

Open Google Chrome. In the address bar, type the following URL and press Enter:

chrome://extensions/

Step 4: Enable Developer Mode

On the Chrome Extensions page, look at the top-right corner. You will see a toggle switch labeled "Developer mode".

Click the toggle to turn Developer mode ON.

Step 5: Load the Unpacked Extension

Once Developer mode is enabled, new buttons will appear at the top of the Extensions page.

Click "Load unpacked".

A file selection window will appear. Navigate to the folder you extracted in Step 2.

Open the extracted repository folder and locate the AI Screen Reader folder containing the extension's manifest.json file.

Select that folder and click "Select Folder".

Step 6: Pin & Use!

The AI Screen Reader extension is now installed.

For easy access, click the puzzle-piece Extensions icon in Chrome's top-right toolbar.

Find "AI Screen Reader" and click the Pin icon.

Click the pinned AI Screen Reader icon on any supported webpage or PDF to start listening.
```
