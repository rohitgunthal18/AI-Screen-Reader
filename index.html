How to Install & Configure on Chrome

Since we are not on the Chrome Web Store, follow these simple steps to load the extension manually:

Step 1: Download the Extension

First, download the extension ZIP file to your computer.

Download ZIP File

Step 2: Extract the ZIP File

Locate the downloaded ZIP file on your computer, right-click it, and select "Extract All..." (Windows) or double-click to unzip (Mac). Remember the folder location where you extracted it.

Step 3: Open Chrome Extensions Page

Open Google Chrome. In the address bar, type the following URL and press Enter:

chrome://extensions/

Step 4: Enable Developer Mode

In the top right corner of the Extensions page, you will see a toggle switch labeled "Developer mode". Click it to turn it ON.

Step 5: Load the Unpacked Extension

Once Developer mode is on, three new buttons will appear in the top left. Click the one that says "Load unpacked".

A file dialog will open. Navigate to the folder where you extracted the ZIP file in Step 2, select the folder, and click "Select Folder".

Step 6: Pin & Use!

The extension is now installed! For easy access, click the "puzzle piece" Extensions icon in Chrome's top right toolbar, find "AI Screen Reader", and click the Pin icon.

Click the pinned icon on any webpage or PDF to start listening.
